# arm-glory-
#重振arm荣光
在浏览器里当芯片架构师：选 die 面积、一颗一颗摆 CPU/GPU 核心、超频跑分。
Being a chip architect in the browser: choosing die size, placing CPU/GPU cores one by one, overclocking for scores.

## 关于制作
## about make
这是一个 AI 辅助的个人项目：代码、美术、音乐均由 AI 生成，我负责写 prompt、定规则、调数值、反复试玩。前后约 8000 字 prompt，单文件 HTML，无外部依赖，不加载任何框架或 CDN。
This is an AI-assisted personal project: the code, art, and music are all generated by AI. I handle writing prompts, setting rules, tweaking values, and playtesting repeatedly. About 8,000 words of prompts in total, all in a single HTML file, no external dependencies, and no frameworks or CDNs loaded.

## Feedback
